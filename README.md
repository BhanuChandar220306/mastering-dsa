This repository is automated using LeetSync, a browser extension that bridges my LeetCode activity directly with GitHub.

Automated Syncing: Every accepted solution is pushed instantly.

Organized Structure: Solutions are categorized neatly by problem name, difficulty, and language.

Progress Tracking: Acts as a portfolio of my technical growth and logical thinking over time.
